# SIMPLE-SUBSTITUTION-CIPHER
Extremely elementary code for demonstrating how substitution ciphers work.

## Generating the key
The `generate_key.py` file create two `.dat` files that contain the encryption and decryption keys. Only letters from the English alphabet are substituted, using some random permutation.

## Encryption
Once the keys are generated by running the `generate_key.py` script, any text file in the same directory as all these files can be encrypted using the `encrypt.py` script by passing the file name in the argument of the bash command.
For example: `python encrypt.py plaintext.txt` encrypts `plaintext.txt` and creates a file `ciphertext.txt` containing the encrypted message.

## Decryption
The generated keys can be shared to others, and then any text file in the same directory as all these files can be decrypted using the `decrypt.py` script in a similar manner.
